    Show leaderboards by themselves

    Each auto show below has its own timer, position and size. For example: the champions every 45 minutes at the top, and a small bits board every 20 minutes in a corner. !topvips, !vipchamps and the other commands keep the position and size set on their own tabs. Colours, fonts and animations come from the Boards and Champs tabs.

    Use the link at the top to run every auto show in one browser source. Or use each show's own Copy link to put it in a different scene. Don't add the same show both ways, or it'll pop up twice.

    Want a show to run only while its scene is on screen? In that browser source's properties in OBS, tick Shutdown source when not visible. Its timer then starts again each time you switch to that scene.

    Shows in the same link wait for each other if they come due within a minute. Shows in different links can't see each other, so Streamer.bot skips any auto show that comes within a minute of the last one.

    Auto show needs its own browser source in OBS, made with one of the links on this tab. Your Leaderboards and Champs browser sources don't run it.     Steals

    • 5 animations: Knockout, Slam, Yoink, Rocket, Bowling, or Random

    • Banner: show or hide, custom message with {new}, {old} and {amount}, optional bits/subs line, time on screen
    • Sound: your own file, volume, test button, and when it plays
    • Look: 6 colour themes plus 13 colour pickers, fonts, position and size

    • Bits, Gifted subs, Sub streak and Watch streak can each have their own steal animation, message, timing, sound and colours

    Leaderboards

    • Commands: !topvips, !topwatchstreak, !topsubstreak, !topgifters, !topbits

    • Order: reorder, rename or skip boards in !topvips
    • Timing: seconds per board and for a single board
    • Champions: optional board at the end of !topvips
    • Look: header, photo, sound, colours, fonts, position, size, and 11 show and hide animations

    Stream recap

    • Automatic: shows when you switch to a chosen OBS scene, picked from a list loaded from OBS
    • 8 styles: Classic, Podrace start, Space crawl, Treasure map, Heavy metal slam, Confetti party, Fireworks, Glitch
    • Timing: wait before showing, seconds on screen, or stay until you switch scene

    Connecting

    Not connecting? ("Can't reach Streamer.bot")
    1. Open Streamer.bot and go to Servers/Clients > WebSocket Server.
    2. Tick Auto Start and click Start Server. If it was already running, click Stop Server then Start Server.
    3. Check the Port there matches the Port on the General tab here (usually 8080).
    4. Click Copy link again and paste it into the OBS browser source.
    5. Still stuck? Open Streamer.bot Connection Test.html on the PC that runs OBS and click Test the connection. It tells you what's wrong.
    It says that port is OBS's, not Streamer.bot's
    1. Port 4455 is OBS's own WebSocket. The overlay needs Streamer.bot's WebSocket Server port instead.
    2. On the General tab, set the Port to the one shown in Streamer.bot under Servers/Clients > WebSocket Server (usually 8080), then copy the link again.
    It asks for a password, or says the password is wrong
    1. In Streamer.bot, Servers/Clients > WebSocket Server: if Authentication is ticked, copy its password.
    2. Paste it into Password on the General tab here, or untick Authentication in Streamer.bot and leave it empty.
    3. Copy the link again and paste it into OBS.
    Which PC does what? (one PC, two PCs, OBS on both)
    1. The overlay goes in the OBS you stream from. Open this page and keep the overlay folder on that PC.
    2. Everything on one PC: Streamer.bot's WebSocket Server Address 127.0.0.1, and the same on the General tab here.
    3. Streamer.bot on one PC, streaming OBS on the other: see the next guide.
    4. OBS on both PCs: only the streaming OBS needs the overlay. If it's on the Streamer.bot PC, treat it as one PC; if not, treat it as two PCs.
    5. Streamer.bot on both PCs: run AutoVIP in only one of them, and point the overlay at that one.
    6. Not sure? Open Streamer.bot Connection Test.html on the streaming PC. It has a guide for every setup and finds the right settings for you.
    Streamer.bot and OBS are on different PCs
    1. On the Streamer.bot PC: set the WebSocket Server Address to 0.0.0.0, then Stop and Start the server. Click Allow if Windows asks about the firewall.
    2. Find that PC's IP: in OBS on that PC, go to Tools > WebSocket Server Settings > Show Connect Info and use the Server IP. No OBS on that PC? Open Command Prompt, type ipconfig and use the IPv4 Address.
    3. On the General tab here, put that IP in Address.
    4. Copy the whole folder (overlay, this page, sounds and pictures) onto the OBS PC, open this page there, and copy the link from there.

    Settings and OBS

    Where do my sounds and pictures go?
    1. Put every sound (mp3, wav or ogg) and every picture in the same folder as the overlay file, next to this settings page.
    2. Keep the overlay, this settings page and the Connection Test page together in that folder too. Don't move or rename them afterwards.
    3. Pick sounds and pictures with Browse... from inside that folder. Only the file name is saved, so a file anywhere else won't be found.
    4. Moving to another PC? Copy the whole folder across, then copy the link again from this page on that PC.
    My picture doesn't show
    1. Check the picture is in the same folder as the overlay file, and the file name matches exactly, including the ending (.png, .jpg or .gif).
    2. Check Show photo is ticked for that part.
    3. Copy the link again and paste it into OBS.
    I changed something but OBS still shows the old look
    1. Your settings live inside the link, so OBS only sees changes after you copy it again.
    2. Click Copy link on that part's tab.
    3. In OBS, double-click the browser source, clear the URL box completely, paste, and click OK.
    It says the link is broken

    Two links were pasted on top of each other. In OBS, clear the URL box completely, then paste the link from this page once.

    My settings have disappeared
    1. This page saves your settings in the web browser you opened it in, on that PC only.
    2. Open it in the same browser on the same PC to get them back. On another PC or browser you'll need to set them up again.
    3. Your OBS link still has your settings in it, so the overlay keeps working either way.
    It's too big, too small or cut off
    1. In OBS, set the browser source Width to 2560 and Height to 1440, then right-click it > Transform > Fit to screen.
    2. Leave Overall size on the General tab at 1.
    3. To make one part smaller, use its Size slider (30% to 100%) under Position and size, then copy the link again.
    No sound
    1. Test sound works but OBS is silent? You picked the sound after copying the link. Copy the link again, clear the URL box in OBS and paste it in.
    2. The preview stays quiet while you change settings. Click a Preview button to hear the sound.
    3. Keep the sound file in the same folder as the overlay file (see Where do my sounds and pictures go?). Use Test sound here to check it plays.
    4. In OBS, open the browser source and tick Control audio via OBS, then check it isn't muted in the audio mixer.
    5. Check the Volume slider for that part isn't at 0, then copy the link again.

    Commands and leaderboards

    Nothing happens when someone types !topvips (or another command)
    1. Check the browser source for leaderboards is in the scene you're on in OBS.
    2. In Streamer.bot, check the command is ticked on the Commands tab and the AutoVIP actions are switched on.
    3. Open the AUTOVIP action, double-click Execute C# Code and click Compile. It should say it compiled successfully.
    4. Check the overlay is connected (see Not connecting? above).
    It says Streamer.bot couldn't run an action

    Re-import AutoVIP into Streamer.bot so the action exists, and make sure the action is switched on.

    Someone is missing from a leaderboard
    1. Mods, editors, bots, the broadcaster, VIPs you gave by hand and anyone on VIP_BLOCK_LIST never appear on the boards.
    2. Watch streaks go up when the stream ends, for everyone who was in chat while you were live. Streamer.bot's broadcaster account needs the moderator:read:chatters permission to see lurkers.
    3. Sub streaks only update when the viewer shares their resub in chat with the streak option turned on.
    How do I test without waiting for a real steal?
    1. Type !teststeal in chat (mods and the broadcaster only). It plays a steal on screen and nobody's VIP changes.
    2. The preview on this page also shows each part as you change it.

    Recap and auto show

    The end of stream recap doesn't show
    1. On the Recap tab, tick Show end of stream recap when on scene.
    2. In OBS: Tools > WebSocket Server Settings > tick Enable WebSocket server. Put its details under OBS connection and click Connect and get scenes.
    3. Pick your end screen in Scene and copy the link again.
    4. Put the recap browser source only in that scene, and in its properties tick Shutdown source when not visible and Refresh browser when scene becomes active.
    Auto show isn't showing anything
    1. On the Auto tab, check Turn on auto show is ticked, and Turn this one on for that show.
    2. Auto show needs its own browser source. Copy the link at the top of the Auto tab (or that show's own link), clear the URL box in OBS and paste it in. Your Leaderboards and Champs browser sources don't run it.
    3. If Only while live is ticked, it waits until you're live. It also waits for First one after (minutes), and that countdown starts again whenever the browser source reloads (or, with Shutdown source when not visible, each time you switch to its scene).
    4. Shows in different links can't see each other: if two come due within a minute, Streamer.bot skips the second. Move one of them a few minutes, or put them in the same link.
    5. The auto show browser source must be connected to Streamer.bot (see Not connecting? above).
    6. To test it quickly, set First one after to 1, copy the link again, and set it back afterwards.
    An auto show pops up twice
    1. The same show is in two browser sources: the link at the top of the Auto tab runs every show, so don't also add that show's own link.
    2. Either keep the one link for all shows, or use only each show's own link.
    Auto show also pops up in my !topvips or !vipchamps browser source
    1. Your AutoVIP code in Streamer.bot is older than this overlay, so it doesn't mark which shows are automatic.
    2. Import the AutoVIP file from this folder again, then put your settings back at the top of the code.
