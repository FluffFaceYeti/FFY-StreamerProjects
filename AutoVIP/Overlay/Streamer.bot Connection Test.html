Streamer.bot Connection Test

Open this on the PC that runs OBS, with Streamer.bot and OBS both open, then click the button.

It looks for Streamer.bot and OBS and tells you exactly what to put in the overlay settings.

Which setup do you have?

The overlay lives in the OBS you stream from. Always run this test, and keep the overlay folder, on the PC whose OBS streams. Click your setup:

Everything on one PC (Streamer.bot and OBS together)
  1. In Streamer.bot: Servers/Clients > WebSocket Server, Address 127.0.0.1, Port 8080, tick Auto Start, click Start Server.
  2. Leave the box below empty and click Test the connection.
  3. On the settings page's General tab: Address 127.0.0.1, Port 8080.
Streamer.bot on one PC, OBS (streaming) on the other
  1. On the Streamer.bot PC: Servers/Clients > WebSocket Server, Address 0.0.0.0, Port 8080, tick Auto Start, then Stop Server and Start Server. Click Allow if Windows asks about the firewall.
  2. Find the Streamer.bot PC's IP (how: see the box below the setups).
  3. Copy the whole overlay folder onto the OBS PC, and open this test there.
  4. Type the Streamer.bot PC's IP in the box below and click Test the connection.
  5. On the settings page's General tab (opened on the OBS PC): Address = the Streamer.bot PC's IP, Port 8080.
OBS on both PCs, Streamer.bot on one of them
  1. Decide which OBS you stream from. The overlay only goes in that one.
  2. If the streaming OBS is on the same PC as Streamer.bot: follow Everything on one PC.
  3. If the streaming OBS is on the other PC: follow Streamer.bot on one PC, OBS on the other.
  4. The other OBS doesn't need anything from AutoVIP.
Streamer.bot on both PCs
  1. Only run AutoVIP in one Streamer.bot. In the other one, switch the AutoVIP actions and the Auto VIP Refresh timer off (or don't import it there), or they'll fight over the same VIPs.
  2. Point the overlay at the Streamer.bot that runs AutoVIP, using whichever setup above matches where it is.
What about the end of stream recap's OBS connection?

The recap talks to the OBS it's shown in, which is the OBS on the PC you run this test on. So on the Recap tab it's always Address 127.0.0.1 plus the port this test finds (usually 4455), even with two PCs. Streamer.bot doesn't need its own OBS connection for AutoVIP.

Only if Streamer.bot runs on another PC: type that PC's IP address. Leave it empty if everything is on this PC.
Easiest way to find it: on the Streamer.bot PC, open OBS and go to Tools > WebSocket Server Settings > Show Connect Info. The Server IP is the one you want.
No OBS on that PC? Open Command Prompt there, type ipconfig and use the IPv4 Address.
