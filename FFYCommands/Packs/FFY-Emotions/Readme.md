# FFY Emotions

How happy, angry, caffeinated or hangry chat is feeling today, plus a few more.

This is a pack for **FFY Commands**. Install that first if you haven't already.

## Installing

Download **`FFY-Emotions`** from this page. Over in Streamer.bot, click **Import** at the top, drag it into the box and click **Import**.

Everything's switched on already. Give `!happiness` a go in chat.

Don't want all of them? Open the **FFY Emotions** folder in the **Commands** tab and untick **Enabled** on any you'd rather not have.

## Tweaking it

Everything's in the **FFY Emotions** group in the **Actions** tab. To change something, open the action, double-click **Execute C# Code**, edit the lines between `EDIT BELOW` and `EDIT ABOVE` and hit **Save and Compile**.

| Action | What's in it |
|---|---|
| **FFY Emotions** | Settings and replies for its commands |
| **FFY Emotions Triggers** | Connects the commands to FFY Commands. Don't edit its code |
| **FFY Emotions Setup** | Runs once on import |

> Updating the pack replaces these actions, so if you want a change to stick, put it in **FFY My Number Commands** (in FFY Commands) instead. See [Keeping your changes safe from updates](../../QuickGuide.md#21-keeping-your-changes-safe-from-updates).

## Not working?

If nothing replies at all, check **FFY Commands** is installed and look in the **Logs** tab for `[FFY Emotions]`. If it's just one command that's quiet, make sure it's switched on in the **FFY Emotions** folder in the **Commands** tab.

If it's something else, have a look at the [troubleshooting section](../../QuickGuide.md#28-troubleshooting) in the FFY Commands guide.
