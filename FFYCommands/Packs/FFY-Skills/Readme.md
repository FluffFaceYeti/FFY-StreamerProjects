# FFY Skills

Aim, stealth, cooking, flirting and more. A pack for **FFY Commands**.

> **You need FFY Commands installed first.** Install FFY Commands, then this pack.

---

## Installing

1. Make sure **FFY Commands** is already installed.
2. Download the **`FFY-Skills`** file from this page.
3. In Streamer.bot, click **Import** in the bar at the top, drag and drop the file into the box, and click **Import**.

Done. The commands are switched on for you. Type `!precision` in chat to test.

**Only want some of them?** In the **Commands** tab, open the **FFY Skills** folder and untick **Enabled** on the ones you don't want.

## Changing things

Everything is in the **Actions** tab, in the **FFY Skills** group. Open an action, double-click **Execute C# Code**, change the lines between `EDIT BELOW` and `EDIT ABOVE`, and click **Save and Compile**.

| Action | What's in it |
|---|---|
| **FFY Skills** | Settings and replies for its commands |
| **FFY Skills Triggers** | Connects the commands to FFY Commands. Don't edit its code |
| **FFY Skills Setup** | Runs once on import |

> **Updating this pack replaces these actions.** To keep a change safe, put it in **FFY My Number Commands** (in FFY Commands) instead. See [Keeping your changes safe from updates](../../QuickGuide.md#21-keeping-your-changes-safe-from-updates).

## Troubleshooting

- **No reply at all:** is **FFY Commands** installed? Check the **Logs** tab for `[FFY Skills]`.
- **One command doesn't reply:** is it switched on in the **Commands** tab (the **FFY Skills** folder)?
- **Anything else:** see the [troubleshooting section](../../QuickGuide.md#28-troubleshooting) in the FFY Commands guide.
