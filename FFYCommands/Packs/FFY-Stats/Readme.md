# FFY Stats

The classics. Beard, PP, daddy, mommy, sigma, brainrot and loads more, with their "of the Day" titles.

It's a pack for **FFY Commands**, so install that first.

## Installing

Download the **`FFY-Stats`** file from this page. In Streamer.bot, click **Import** at the top, drag the file into the box and click **Import**.

That's it, the commands are already switched on. Try `!beard` in chat.

If there are a few you don't want, go to the **Commands** tab, open the **FFY Stats** folder and untick **Enabled** on those.

## Changing things

Head to the **Actions** tab and open the **FFY Stats** group. Double-click **Execute C# Code** in the action you want, change the bits between `EDIT BELOW` and `EDIT ABOVE`, and click **Save and Compile** when you're done.

| Action | What's in it |
|---|---|
| **FFY Stats** | Settings and replies for its commands |
| **FFY Stats Of The Day** | The "of the Day" titles |
| **FFY Stats Triggers** | Connects the commands to FFY Commands. Don't edit its code |
| **FFY Stats Setup** | Runs once on import |

> Updating the pack replaces these actions, so if you want a change to stick, put it in **FFY My Number Commands** (in FFY Commands) instead. See [Keeping your changes safe from updates](../../QuickGuide.md#21-keeping-your-changes-safe-from-updates).

## Troubleshooting

- **Nothing replies:** is **FFY Commands** installed? Look for `[FFY Stats]` in the **Logs** tab.
- **Only one command is quiet:** check it's switched on in the **Commands** tab, in the **FFY Stats** folder.

If it's something else, have a look at the [troubleshooting section](../../QuickGuide.md#28-troubleshooting) in the FFY Commands guide.
