# FFY Personality

How much rizz, sass, chaos or main character energy everyone's got today, and a lot more besides.

You need **FFY Commands** installed before adding this pack.

## Installing

Grab the **`FFY-Personality`** file from this page, then in Streamer.bot hit **Import** at the top, drop the file in and click **Import**.

The commands switch on by themselves, so you can type `!clowning` straight away to check it's working.

You can turn off any you don't like. Find them in the **FFY Personality** folder in the **Commands** tab and untick **Enabled**.

## Making changes

It all lives in the **Actions** tab under the **FFY Personality** group. Open an action, double-click **Execute C# Code**, change whatever's between `EDIT BELOW` and `EDIT ABOVE`, then click **Save and Compile**.

| Action | What's in it |
|---|---|
| **FFY Personality** | Settings and replies for its commands |
| **FFY Personality Triggers** | Connects the commands to FFY Commands. Don't edit its code |
| **FFY Personality Setup** | Runs once on import |

> Updating the pack replaces these actions, so if you want a change to stick, put it in **FFY My Number Commands** (in FFY Commands) instead. See [Keeping your changes safe from updates](../../QuickGuide.md#21-keeping-your-changes-safe-from-updates).

## If something's not working

No replies at all usually means **FFY Commands** isn't installed. The **Logs** tab will show `[FFY Personality]` lines if the pack is running. If just one command isn't replying, check it's ticked in the **FFY Personality** folder in the **Commands** tab.

If it's something else, have a look at the [troubleshooting section](../../QuickGuide.md#28-troubleshooting) in the FFY Commands guide.
