The packs have 199 commands. With FFY Commands' own `!leaderboard`, that's 200 in total.

## Installing a pack

1. Make sure **FFY Commands** is installed.
2. Open the pack's folder and download its file (e.g. **`FFY-Stats`**).
3. In Streamer.bot, click **Import** in the bar at the top, drag and drop the file into the box, and click **Import**.

The pack's commands are switched on for you. Install as many packs as you like, in any order.
