# FFY Command Packs

Every pack is a separate import, so you can pick and choose. Install **FFY Commands** first, then add whichever packs you fancy.

| **[FFY Stats](FFY-Stats/Readme.md)** | Beard, PP, daddy, mommy, sigma, brainrot and lots more, with their "of the Day" titles. | 29 |

That's 199 commands across the packs, or 200 once you count `!leaderboard` from FFY Commands itself.

## Installing

With **FFY Commands** already installed, open a pack's folder and download its file (e.g. **`FFY-Stats`**). In Streamer.bot, click **Import** at the top, drag the file in and click **Import**.

The commands switch on by themselves. Add as many packs as you want, in any order.
