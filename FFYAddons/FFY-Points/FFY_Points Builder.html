Point events
Start one with !pointevent hunt, or the command on its own for a random one. Everyone who types the join command is in, and random winners each get the prize. Pictures, GIFs, videos and sounds show on the overlay. Use a link, or a file saved on your PC: press Browse or drag the file onto the box.in File Explorer, hold Shift, right-click the file, pick Copy as path and paste it in.

Chat messages
You can use {name} for your points name, {user}, {target}, {amount}, {points} and {list}. In events: {title}, {prize}, {winners}, {seconds} and {join}.
{amount} is the bonus, {count} is how many people got it.
Points are kept in Streamer.bot. Making a new import and importing it again never resets anyone's points.
Your import
    1. In Streamer.bot, click Import at the top, paste it in and click Import.
    2. For points from watching, go to Platforms > Twitch > Settings in Streamer.bot and make sure Present Viewers is on.
    3. For point events on stream, press Save the overlay file, keep it somewhere safe, and add it to OBS as a Browser Source with Local file ticked.
    Load settings
    This page remembers your settings in this browser. Somewhere else? Paste an import this page made and press Load.
