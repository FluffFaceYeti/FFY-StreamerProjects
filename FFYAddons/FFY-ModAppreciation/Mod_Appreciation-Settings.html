Streamer.bot connection

Address: use 127.0.0.1 if OBS and Streamer.bot are on the same PC. On a dual PC setup, use the IP address of the PC running Streamer.bot, e.g. 192.168.1.20. Streamer.bot itself can stay on 0.0.0.0. Copy the port and endpoint from Streamer.bot: Servers/Clients > WebSocket Server, and make sure it's running. Only fill in the password if you switched on Authentication there. It's saved inside the link, so don't share the link.
