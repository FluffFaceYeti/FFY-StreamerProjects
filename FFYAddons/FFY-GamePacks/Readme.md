# FFY Game Packs

Commands for the game you're streaming. Each game is a separate import, so you only need the ones you actually play.

You'll need **FFY Commands** installed first, as these all plug into it.

| Game | What's in it |
|---|---|
| **[FFY Fortnite](FFY-Fortnite/Readme.md)** | `!victoryroyale`, `!vbucks`, `!elims`, `!drop`, `!emote`, `!fortniteskin`, `!loot`, `!emoteon @someone`, a `!boxfight @someone` and Victory Royale of the Day. 14 commands |
| **[FFY Minecraft](FFY-Minecraft/Readme.md)** | `!diamonds`, `!creeperluck`, `!biome`, `!mob`, `!craft`, `!mcdeath`, `!tnt @someone`, a `!pvp @someone` duel and Diamond Miner of the Day. 13 commands |
| **[FFY Gears Of War](FFY-Gears-Of-War/Readme.md)** | `!activereload`, `!gnasher`, `!lancer`, `!gearsweapon`, `!gearsquote`, `!curbstomp @someone`, a `!chainsaw @someone` duel, plus COG and Locust of the Day. 20 commands |

## Installing

Check **[FFY Commands](../../FFYCommands/Readme.md)** is installed, then open the game's folder and download its file. In Streamer.bot, click **Import** at the top, drag the file in and click **Import**.
