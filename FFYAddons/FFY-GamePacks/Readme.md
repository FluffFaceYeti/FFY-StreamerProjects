# FFY Game Packs

Commands for the game you're playing. Each game is its own import, so you only add the ones you stream.

> **You need FFY Commands installed first.** These all plug into it.

| Game | What's in it |
|---|---|
| **[FFY Fortnite](FFY-Fortnite/Readme.md)** | `!victoryroyale`, `!vbucks`, `!elims`, `!drop`, `!emote`, `!fortniteskin`, `!loot`, `!emoteon @someone`, a `!boxfight @someone` and Victory Royale of the Day. 14 commands |
| **[FFY Minecraft](FFY-Minecraft/Readme.md)** | `!diamonds`, `!creeperluck`, `!biome`, `!mob`, `!craft`, `!mcdeath`, `!tnt @someone`, a `!pvp @someone` duel and Diamond Miner of the Day. 13 commands |
| **[FFY Gears Of War](FFY-Gears-Of-War/Readme.md)** | `!activereload`, `!gnasher`, `!lancer`, `!gearsweapon`, `!gearsquote`, `!curbstomp @someone`, a `!chainsaw @someone` duel, COG and Locust of the Day. 20 commands |

## Installing a game pack

1. Make sure **[FFY Commands](../../FFYCommands/Readme.md)** is installed.
2. Open the game's folder above and download its file.
3. In Streamer.bot, click **Import** in the bar at the top, drag and drop the file into the box, and click **Import**.
